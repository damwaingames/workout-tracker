# The wind-down is a daily freeform mobility habit, not a session or a per-routine segment

The **Wind-down** is a **daily habit** — an evening mobility routine done most nights, **winged**:
you stretch whatever feels like it needs it (always roughly similar), not a composed, progressed
plan you follow. It is tracked as a daily done-record rolled up to a **weekly adherence** target (a
target number of nights — this user aims for ~6 of 7, typically resting Sunday), kept *outside* the
**block** the way body **measurements** are a periodic record; if you happen to log specific
stretches, those are ordinary **performances** on mobility **exercises**, nothing special.

It is deliberately **not** a planned training **Session** — no **rails**, no progression, no fixed
content — and **not** a post-workout cool-down segment bolted under routines. This supersedes
ADR-0013, which modelled it as a shared segment shown beneath every non-rest routine: the wrong
shape twice over — it is neither attached to workouts nor a prescribed list. Supersedes ADR-0013.

## Consequences

- App-level and outside the block — a daily constant, not a weekday **routine**.
- Deliberately unplanned: forcing a fixed nightly list would fight how it is actually done (by feel).
  If a consistent prescribed routine is ever wanted, that is a new decision, not this one.
